🚀 Project Showcase: Banking Transaction Analysis using SQL Server

I built a SQL-based Banking Transaction Analysis project to practise solving practical business questions with relational data.

🔎 What I analysed:
• Transaction volume and total amount by transaction type
• Successful vs. failed transaction patterns
• High-value transactions and average transaction comparisons
• Customer-level transaction totals and activity
• City-level transaction trends and transaction success rates
• Customer ranking using SQL window functions

🛠️ SQL concepts used:
SELECT, WHERE, ORDER BY, GROUP BY, HAVING, aggregate functions, INNER JOIN, subqueries, CTEs, CASE expressions, and DENSE_RANK().

📌 Key findings from the synthetic dataset:
• 20 transactions with a total value of ₹357,000
• 18 successful transactions totalling ₹332,000
• Deposits represented the largest transaction-type total at ₹222,000

This project helped me practise translating business questions into SQL queries and interpreting results carefully. The dataset is synthetic and used for learning purposes.
